# Meek网桥模式下Tor匿名通信系统加密流量数据说明

## 一、数据内容描述
### 1.1 数据概述
Meek网桥模式下Tor匿名通信系统加密流量数据集是由中国电子科技集团第三十研究所建立的一个Meek网桥模式下Tor通信流量的数据集，记录了Tor匿名通信系统与应用通信软件在通信过程中产生的流量数据，可支撑对深暗网常用应用的识别功能。
该数据集主要包含本地客户端到Meek网桥的TCP协议通信的加密流量，且含有背景流量与其余协议流量。

### 1.2内容描述
Meek网桥模式下Tor匿名通信系统加密流量数据集，包含了2021年1月12日至14日内在成都采集的windows系统下10.0.16版本的Tor浏览器的Meek网桥的TCP原始通信流量，含有20个pcap文件，其数据量为1.84 GB。由于该数据集由pcap文件构成，其中 Meek网桥流量的会话信息如下：

|源IP地址|	目的IP地址|	目的端口|
|-------|-----------|-------|
|10.38.0.213|	117.18.232.200|	443|

### 1.3 目录结构描述
Meek网桥模式下Tor匿名通信系统加密流量数据集，其采集的加密流量均采用pcap数据格式存储至该目录下，不具有其余的目录结构与文件夹。
其中加密流量的命名格则采用加密流量类型结合编号，如`tor_meek_1.pcap`。

### 1.4 文件描述
Meek网桥模式下Tor匿名通信系统加密流量数据集中的数据文件为pcap格式。
pcap是一种数据流格式，wireshark软件可以直接把网络数据流转为pcap，其格式如下图所示，整个数据流文件，只会有一个Global Header，它定义了本文件的读取规则、最大储存长度限制等内容，共24 Byte；可以有多个Packet Header，每个Packet Header后面会跟着一串Packet Data，Packet Header定义了Packet Data的长度、时间戳等信息。

## 二、使用说明
### 2.1 共享说明
本数据集完全共享。

### 2.2使用说明
该数据适用于对深网暗网通信协议及应用软件进行识别的相关研究，可通过提取pacp的流量特征进行深度分析与建模，保障研究的有效性与可靠性。
由于Meek网桥模式下Tor匿名通信系统加密流量数据采用通用数据格式，不需要采用专用辅助工具进行处理、加工和分析。
