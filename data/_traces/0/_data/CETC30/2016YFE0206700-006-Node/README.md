# 深网暗网网络节点数据库数据说明

## 一、数据内容描述
### 1.1 数据概述
深网暗网网络节点数据库是由中国电子科技集团第三十研究所建立的一个包含Tor、I2P、ZeroNet、FreeNet网络节点的数据库，记录了常见暗网的网络节点，可支撑对深暗网网络结构的分析，含有Tor网络节点数据、ZeroNet网络节点数据、FreeNet网络节点数据以及I2P网络节点数据。
该数据库主要包含网络类型、节点IP、端口、国家名称、探测时间等数据项，其中网络类型有Tor、I2P、ZeroNet与FreeNet。

### 1.2 内容描述
深网暗网网络节点数据库，包含了2019年1月至2020年2月内的Tor、ZeroNet、I2P、FreeNet四个深网暗网的节点数据，含有381836条记录数，预估数据量为18.9MB。
由于深网暗网网络节点数据为csv文件，且文件的主要数据是网络节点的IP等基础信息，不需要额外的计算方式。

### 1.3 目录结构描述
深网暗网网络节点数据库，共含有1个文件，其中包含Tor网络节点数据、ZeroNet网络节点数据、FreeNet网络节点数据以及I2P网络节点数据，代表不同的深网暗网类型。
其中文件夹中的文件命名采用网络节点结合采集或者加工时间命名，如深网暗网网络节点20210618.csv。

### 1.4 文件描述
深网暗网网络节点数据库采用csv格式保存文件，其字段对应的格式与含义如下表所示：

| 字段名  | 字段类型 | 字段长度 | 是否键值 | 字段含义                               |
| ------- | -------- | -------- | -------- | -------------------------------------- |
| id      | int      | 64       | 是       | 自增ID                                 |
| key     | varchar  | 128      | 否       | 节点唯一标识符                         |
| netType | varchar  | 8        | 否       | 网络类型（Tor、I2P、ZeroNet、FreeNet） |
| ip      | varchar  | 64       | 否       | 节点IP                                 |
| port    | int      | 11       | 否       | 端口                                   |
| country | varchar  | 64       | 否       | 国家名称                               |
| time    | datetime | 6        | 否       | 探测时间                               |

## 二、使用说明
### 2.1 共享说明
本数据集完全共享。

### 2.2 使用说明
该数据库适用于对深网暗网通信网络进行网络拓扑测绘的相关研究，可基于网络节点IP地址等信息，便于后续分析。
由于深网暗网网络节点数据库采用通用数据格式，不需要采用专用辅助工具进行处理、加工和分析。
